Tujuan Pembelajaran (Bab 1 – 7)

Selamat datang di modul pembelajaran pemrograman aplikasi dan web. Sebelum memulai petualangan kodingmu, pahami target dan kompetensi yang akan kamu capai di setiap bab berikut ini.

7 Bab Terstruktur Dari logika komputasional hingga aplikasi web nyata
Praktik Langsung Disertai contoh kode, simulasi, kuis, dan mini game
Kurikulum Merdeka Fase E (Kelas X SMA) Elemen Algoritma & Pemrograman
Bab 1

Dasar Algoritma & Pemrograman

Membangun fondasi logika berpikir komputasional sebelum menulis kode pertamamu.

Sasaran Pembelajaran:
  • Memahami definisi algoritma serta 5 kriteria algoritma yang baik dan efektif.
  • Mampu membaca dan menyusun representasi logika menggunakan flowchart dan pseudocode.
  • Menguasai konsep variabel, konstanta, dan tipe data dasar komputer.
  • Menerapkan struktur kontrol logika percabangan (if-else) dan perulangan (looping).
  • Menerapkan prinsip praktik baik penulisan kode yang bersih, bermakna, dan mudah dipelihara.
Bab 2

Bagaimana Web Bekerja

Menyingkap teknologi jaringan dan infrastruktur di balik internet modern.

Sasaran Pembelajaran:
  • Menjelaskan arsitektur komputasi Client – Server dalam interaksi web.
  • Memahami alur siklus permintaan dan respons (Request – Response cycle).
  • Menganalisis perbedaan serta tingkat keamanan protokol HTTP dan HTTPS (SSL/TLS).
  • Memahami peran Domain Name System (DNS) dalam memetakan nama domain ke alamat IP.
  • Membedah anatomi struktur URL (protokol, domain/host, port, path, query string, dan hash).
Bab 3

HTML: Struktur Halaman Web

Mempelajari kerangka dasar dan semantik dalam membangun konten halaman web.

Sasaran Pembelajaran:
  • Memahami peran HTML sebagai bahasa markah pembangun struktur web.
  • Menguasai anatomi elemen HTML: tag pembuka, atribut, konten, dan tag penutup.
  • Menyusun dokumen HTML standar lengkap (<!DOCTYPE>, <html>, <head>, <body>).
  • Menggunakan tag-tag esensial: heading, paragraf, tautan (<a>), gambar (<img>), list, dan tabel.
  • Menerapkan HTML Semantik (<header>, <nav>, <main>, <article>, <footer>) untuk aksesibilitas & SEO.
  • Membuat formulir input interaktif (<form>, <input>, <select>, <button>).
Bab 4

CSS: Tampilan & Tata Letak

Menghias, memberi gaya, dan mengatur tata letak antarmuka web yang rapi dan memukau.

Sasaran Pembelajaran:
  • Memahami 3 metode penerapan CSS (inline, internal, dan external stylesheet).
  • Menguasai selektor dasar: element, class, ID, dan hierarki spesifisitas (*cascade*).
  • Memahami konsep vital Box Model: margin, border, padding, dan content.
  • Membangun layout modern satu dimensi yang fleksibel menggunakan CSS Flexbox.
  • Menerapkan prinsip Responsive Web Design dengan media queries agar ramah di HP dan laptop.
Bab 5

JavaScript: Interaktivitas Web

Menghidupkan halaman web statis agar interaktif dan merespons aksi pengguna secara langsung.

Sasaran Pembelajaran:
  • Memahami kedudukan JavaScript sebagai bahasa pemrograman interaktif sisi klien (client-side).
  • Mendeklarasikan variabel modern (let, const) dan memahami tipe data di JS.
  • Memanipulasi Document Object Model (DOM): memilih, membaca, dan mengubah elemen HTML.
  • Menangani interaksi pengguna melalui Event Listener (click, input, submit).
  • Mampu membangun mini proyek web interaktif (studi kasus aplikasi Todo List).
Bab 6

Dari Web ke Aplikasi

Mengenal ekosistem aplikasi modern, REST API, dan kolaborasi kode dengan Git.

Sasaran Pembelajaran:
  • Membedakan spektrum aplikasi: Web Statis, Web App (SPA), Progressive Web App (PWA), Hybrid, dan Native.
  • Memahami tahapan Software Development Life Cycle (SDLC): analisis, desain, implementasi, uji, rilis.
  • Memahami konsep REST API dan pertukaran data format JSON antara Frontend dan Backend.
  • Mengenal fungsi sistem kendali versi (Git & GitHub) untuk melacak revisi dan kerja sama tim.
Bab 7

Etika, Keamanan & Lisensi

Menjadi pengembang berintegritas tinggi, sadar keamanan siber, dan taat hukum lisensi.

Sasaran Pembelajaran:
  • Mengenali 3 ancaman keamanan web dasar pemula (XSS, SQL Injection, Credential Stuffing) & pencegahannya.
  • Memahami jenis-jenis lisensi kode sumber terbuka (Open Source): MIT, Apache 2.0, GPL, dan hak cipta karya.
  • Menerapkan prinsip etika digital, perlindungan privasi data pengguna, dan pencegahan plagiarisme.
  • Mengetahui peta jalan (*roadmap*) pengembangan keahlian pemrograman lebih lanjut pasca SMA.
Tips Belajar Efektif di CodeNexa: Pelajari setiap materi secara berurutan, coba langsung contoh kodenya, lalu uji pemahamanmu dengan mengikuti Kuis Interaktif dan Mini Game di akhir sesi!
Bab 1

Dasar Algoritma & Pemrograman

Pahami cara berpikir terstruktur sebelum menulis kode pertamamu.

1.1 Algoritma

Algoritma adalah urutan langkah yang jelas dan berhingga untuk menyelesaikan suatu masalah. Contoh sehari-hari: resep memasak, atau langkah mengisi pulsa lewat aplikasi. Algoritma bisa ditulis sebagai kalimat, flowchart, atau pseudocode.

5 Ciri Algoritma yang Baik Ada masukan (input) · ada keluaran (output) · setiap langkah jelas · jumlah langkah berhingga · bersifat efektif (dapat benar-benar dikerjakan).

Flowchart: Menentukan Lulus atau Tidak

1.2 Pemrograman

Pemrograman adalah proses menuliskan algoritma ke dalam bahasa pemrograman agar komputer dapat menjalankannya. Pada Fase E, siswa mempelajari pemrograman prosedural.

Python dijalankan oleh interpreter yang membaca kode langkah demi langkah. JavaScript dijalankan oleh mesin di dalam peramban (browser). Keduanya cocok untuk pemula karena kita bisa mencoba kode dan langsung melihat hasilnya.

1.3 Konsep Dasar

KonsepPenjelasanContoh Python
VariabelWadah bernama untuk menyimpan datanama = "Sari"
Tipe dataBilangan bulat, desimal, teks, benar/salahumur = 16, tinggi = 1.6
OperatorSimbol menghitung atau membandingkan+ - * / == >=
PercabanganMemilih langkah berdasarkan kondisiif, else
PerulanganMengulang langkahfor, while
FungsiBlok kode yang diberi nama, dapat dipakai ulangdef

1.4 Contoh Program Python

def cek_kelulusan(nilai):
    if nilai >= 75:
        return "Lulus"
    else:
        return "Remedial"

for n in [90, 70, 75]:
    print(n, "->", cek_kelulusan(n))

# Output:
# 90 -> Lulus
# 70 -> Remedial
# 75 -> Lulus

1.5 Praktik Baik Penulisan Program

  • Beri nama variabel yang bermakna — nilai_akhir, bukan x.
  • Gunakan indentasi yang konsisten.
  • Tulis komentar untuk menjelaskan mengapa, bukan sekadar apa.
  • Pecah masalah besar menjadi fungsi-fungsi kecil.
  • Uji program dengan beberapa data, termasuk data batas (misal nilai 75 tepat).
Tujuan Pembelajaran Bab 1:
  • Memahami konsep algoritma dan 5 ciri algoritma yang baik & efektif.
  • Membaca dan merancang representasi logika dengan flowchart dan pseudocode.
  • Menguasai variabel, konstanta, dan tipe data dasar komputer.
  • Menerapkan struktur kontrol logika percabangan (if-else) dan perulangan (looping).
  • Menerapkan prinsip praktik baik penulisan kode program.
Bab 2

Bagaimana Web Bekerja

Pahami infrastruktur di balik setiap halaman yang kamu buka.

2.1 Istilah Penting

IstilahPengertian
InternetJaringan global yang menghubungkan jutaan perangkat
WebSalah satu layanan di atas internet (selain email, dll.)
KlienPeramban (Chrome, Firefox) di perangkat pengguna
ServerKomputer yang menyimpan dan mengirim halaman atau data
URLAlamat sumber daya, misal https://contoh.sch.id/profil.html
HTTP/HTTPSProtokol komunikasi klien–server; HTTPS menambahkan enkripsi
DNSMenerjemahkan nama domain menjadi alamat IP
Analogi Restoran Pelanggan (klien) memesan lewat pelayan (HTTP), dapur (server) menyiapkan pesanan, lalu diantar kembali sebagai respons.

2.2 Alur Permintaan dan Respons

1
Pengguna mengetik URL atau mengeklik tautan

Peramban tahu halaman apa yang diminta.

2
Peramban menanyakan alamat IP ke DNS

DNS ibarat buku telepon: mengubah nama domain menjadi alamat IP numerik.

3
Peramban mengirim permintaan (request) ke server

Menggunakan protokol HTTP atau HTTPS.

4
Server mengirim respons

Berisi file HTML, CSS, JavaScript, gambar, atau data JSON.

5
Peramban membaca dan menampilkan halaman

Merender semua file menjadi tampilan yang kamu lihat.

2.3 Front-end vs Back-end

Front-endBack-end
Berjalan diPeramban penggunaServer
TugasTampilan & interaksiLogika, database, keamanan
TeknologiHTML, CSS, JavaScriptPython, PHP, Node.js + database
Fokus Materi Ini Kita berfokus pada front-end — paling mudah dicoba langsung di peramban tanpa perlu server.
Tujuan Pembelajaran Bab 2:
  • Memahami arsitektur Client – Server dan alur siklus Request – Response.
  • Mengetahui perbedaan protokol HTTP vs HTTPS untuk keamanan data internet.
  • Memahami mekanisme kerja Domain Name System (DNS) dalam menerjemahkan domain ke IP.
  • Mengidentifikasi struktur dan anatomi lengkap dari sebuah URL.
Bab 3

HTML: Struktur Halaman

HTML adalah bahasa untuk menyusun struktur dan makna isi halaman web.

HTML memakai elemen yang ditulis dengan tag. Sebuah elemen terdiri atas tag pembuka, isi, dan tag penutup: 

<p>Halo, ini paragraf!</p>

Tag dapat memiliki atribut sebagai keterangan tambahan:

<a href="profil.html">Kunjungi Profil</a>

3.1 Kerangka Dasar HTML

<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Profil Saya</title>
  </head>
  <body>
    <h1>Halo, saya Sari</h1>
    <p>Saya siswa kelas X dan sedang belajar membuat web.</p>
  </body>
</html>
Fungsi tiap bagian:
  • <!DOCTYPE html> — memberitahu peramban ini dokumen HTML5
  • <html lang="id"> — membungkus seluruh halaman, menandai bahasa
  • <head> — info yang tidak tampil: charset, viewport, judul tab
  • <body> — semua konten yang tampil di halaman

3.2 Elemen yang Sering Dipakai

ElemenFungsi
<h1> – <h6>Judul dan subjudul (h1 = paling penting)
<p>Paragraf teks
<a href="...">Tautan (hyperlink)
<img src="..." alt="...">Gambar (alt wajib untuk aksesibilitas)
<ul>, <ol>, <li>Daftar tak berurut / berurut
<table>Tabel data
<form>, <input>, <button>Formulir dan kontrol input

3.3 HTML Semantik

Gunakan elemen yang sesuai maknanya — jangan pakai <div> untuk segalanya:

<body>
  <header><h1>Blog Sekolah</h1></header>
  <nav>
    <a href="#berita">Berita</a> |
    <a href="#kontak">Kontak</a>
  </nav>
  <main>
    <article id="berita">
      <h2>Lomba Robotik</h2>
      <p>Tim kami meraih juara pertama.</p>
    </article>
  </main>
  <footer>&copy; 2026 SMA Contoh</footer>
</body>
Kenapa semantik penting? Membantu pembaca layar (screen reader), mesin pencari (SEO), dan mempermudah pemeliharaan kode jangka panjang.
Tujuan Pembelajaran Bab 3:
  • Memahami peran HTML dan sintaks dasar elemen (tag pembuka, atribut, konten, tag penutup).
  • Menyusun dokumen HTML standar yang valid dan terstruktur rapi.
  • Menggunakan tag-tag esensial: teks, heading, hyperlink, gambar, list, dan tabel.
  • Menerapkan tag HTML Semantik dan membuat formulir web sederhana.
Bab 4

CSS: Tampilan Halaman

CSS mengatur warna, huruf, jarak, dan tata letak halaman web.

CSS (Cascading Style Sheets) dipisahkan dari HTML agar kode lebih rapi dan mudah dikelola.

4.1 Cara Memakai CSS

<!-- Di dalam <head> -->
<link rel="stylesheet" href="gaya.css">

4.2 Aturan CSS

body {
  font-family: Arial, sans-serif;
  margin: 0;
  background-color: #f5f7fa;
  color: #222;
}

h1 { color: #0b5ed7; }

.kartu {
  background: white;
  padding: 16px;
  border-radius: 8px;
  box-shadow: 0 1px 4px rgba(0,0,0,0.15);
}

Bentuk aturan: selektor { properti: nilai; }

SelektorContohMemengaruhi
Elemenh1Semua elemen <h1>
Kelas.kartuSemua elemen ber-class="kartu"
ID#judulSatu elemen ber-id="judul"

4.3 Konsep Penting

Box Model

Lapisan dari dalam ke luar: Konten → Padding (ruang dalam) → Border (garis tepi) → Margin (ruang luar)

Flexbox & Grid

  • Flexbox — menata elemen dalam satu baris atau kolom
  • Grid — tata letak dua dimensi (baris dan kolom)
.daftar {
  display: flex;
  gap: 12px;
  flex-wrap: wrap;
}

@media (max-width: 600px) {
  .daftar {
    flex-direction: column;
  }
}

Responsif dengan Media Query

Gunakan satuan relatif (%, rem) dan media query agar halaman nyaman di semua ukuran layar.

Aksesibilitas Warna Pastikan kontras teks dan latar cukup tinggi. Jangan menyampaikan informasi hanya lewat warna.
Tujuan Pembelajaran Bab 4:
  • Memahami cara kerja CSS dan penerapan selektor (elemen, class, ID).
  • Menguasai konsep Box Model (margin, border, padding, content) dalam tata letak web.
  • Mendesain tata letak antarmuka fleksibel menggunakan CSS Flexbox.
  • Menerapkan Responsive Web Design dengan media queries agar nyaman di berbagai perangkat.
Bab 5

JavaScript: Membuat Halaman Interaktif

JavaScript membuat halaman bereaksi terhadap pengguna.

JavaScript berjalan di peramban. Konsepnya sama seperti Bab 1 (variabel, kondisi, perulangan, fungsi), hanya dengan sintaks yang berbeda.

5.1 Padanan Konsep Python → JavaScript

let nama = "Sari";       // variabel (bisa berubah)
const batas = 75;        // konstanta (tetap)

function cekLulus(nilai) {    // fungsi
  if (nilai >= batas) {        // percabangan
    return "Lulus";
  }
  return "Remedial";
}

for (let i = 1; i <= 5; i++) {  // perulangan
  console.log(i);
}
Python vs JavaScript — Perbedaan Utama:
  • Blok kode pakai { } (bukan indentasi)
  • Setiap pernyataan diakhiri ;
  • Sama-dengan pakai ===, bukan ==
  • Deklarasi variabel: let (bisa berubah) atau const (tetap)

5.2 DOM dan Event

DOM (Document Object Model) adalah representasi halaman HTML sebagai objek yang bisa diubah oleh JavaScript. Event adalah kejadian seperti klik, pengetikan, atau scroll. 

<input id="nilai" type="number" placeholder="Masukkan nilai">
<button id="cek">Cek</button>
<p id="hasil"></p>

<script>
  const tombol = document.getElementById("cek");

  tombol.addEventListener("click", function() {
    const nilai  = Number(document.getElementById("nilai").value);
    const hasil  = nilai >= 75 ? "Lulus" : "Remedial";
    document.getElementById("hasil").textContent = hasil;
  });
</script>
1
getElementById()

Mengambil elemen dari DOM berdasarkan atribut id-nya.

2
addEventListener("click", ...)

Mendaftarkan fungsi yang berjalan saat tombol diklik.

3
.value & Number()

Mengambil isi input (selalu string) lalu mengubahnya menjadi angka.

4
Operator ternary ? :

Singkatan if-else untuk satu baris: kondisi ? jika_ya : jika_tidak

5
.textContent

Menulis teks ke elemen — lebih aman dari innerHTML (mencegah XSS).

5.3 Menyimpan Data Sederhana

Peramban menyediakan localStorage untuk menyimpan data kecil di perangkat pengguna tanpa server.

Perhatian Data di localStorage tidak terenkripsi. Jangan simpan kata sandi atau data pribadi sensitif di sana!

5.4 Debugging

  • Buka konsol peramban dengan F12
  • Gunakan console.log() untuk memeriksa nilai variabel
  • Uji sedikit demi sedikit — jangan tulis banyak kode sebelum menjalankannya
Tujuan Pembelajaran Bab 5:
  • Memahami sintaks dasar JavaScript, deklarasi variabel modern, dan tipe data.
  • Memanipulasi Document Object Model (DOM) untuk mengubah elemen halaman web.
  • Menggunakan Event Listener untuk menangani interaksi pengguna (klik, input form).
  • Membangun logika mini aplikasi interaktif (studi kasus Todo List).

Pahami jenis aplikasi dan tahapan pengembangan perangkat lunak.

6.2 Tahapan Pengembangan Aplikasi

1
Analisis Kebutuhan

Siapa penggunanya? Masalah apa yang diselesaikan?

2
Perancangan

Sketsa tampilan (wireframe), alur penggunaan, dan struktur data.

3
Implementasi

Menulis kode berdasarkan rancangan.

4
Pengujian

Mencoba aplikasi, mencatat dan memperbaiki bug.

5

6.3 Prinsip Dasar UI/UX

  • Konsisten — tombol dan menu berperilaku serupa di semua halaman
  • Sederhana — satu layar, satu tujuan utama
  • Umpan balik jelas — pengguna tahu apakah aksinya berhasil atau gagal
  • Inklusif — teks terbaca, kontras cukup, dapat digunakan dengan keyboard
Tujuan Pembelajaran Bab 6:
  • Membedakan arsitektur aplikasi: Web Statis, Web App, PWA, Hybrid, dan Native.
  • Memahami tahapan siklus hidup Software Development Life Cycle (SDLC).
  • Mengenal fungsi REST API dalam menghubungkan frontend dan backend.
  • Mengenal konsep dasar Git dan version control untuk kolaborasi programmer.
Bab 7

Etika, Keamanan & Lisensi

Menjadi programmer yang bertanggung jawab dimulai dari sini.

Hak Cipta & Lisensi

Gambar, huruf, dan kode milik orang lain punya aturan pemakaian. Cantumkan sumber dan gunakan materi berlisensi terbuka bila memungkinkan.

Data Pribadi

Hanya kumpulkan data yang benar-benar diperlukan dan jelaskan kegunaannya kepada pengguna. Pelajari UU Pelindungan Data Pribadi Indonesia.

Keamanan Dasar

  • Jangan percaya input pengguna begitu saja — selalu validasi input
  • Gunakan HTTPS untuk koneksi terenkripsi
  • Jangan taruh kata sandi atau kunci rahasia di kode yang terlihat di peramban

Integritas Akademik

Boleh belajar dari contoh kode, tetapi pahami dan tulis ulang dengan kata-katamu sendiri. Jika memakai bantuan AI, sebutkan dan pastikan kamu memahami hasilnya.

Dampak Sosial

Pikirkan juga: Siapa yang mungkin tidak bisa memakai aplikasimu? Penyandang disabilitas, pengguna jaringan lambat, atau pengguna perangkat lama?
Tujuan Pembelajaran Bab 7:
  • Memahami ancaman keamanan siber dasar web (XSS, SQL Injection, Credential Stuffing).
  • Mengenal lisensi software dan open-source (MIT, Apache, GPL, Hak Cipta).
  • Menerapkan etika pemrograman, perlindungan privasi data, dan anti-plagiarisme.
  • Mengenal roadmap dan jalur karier programmer di masa depan.
